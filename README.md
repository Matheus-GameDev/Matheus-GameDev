## Como abrir o projeto no VS Code

1. Instale o [Visual Studio Code](https://code.visualstudio.com/) e o [Node.js LTS](https://nodejs.org/).
2. Clone este repositório localmente (`git clone git@github.com:Matheus-GameDev/Matheus-GameDev.git`).
3. Abra um terminal na pasta do projeto e instale as dependências com `npm install`.
4. Inicie o servidor de desenvolvimento com `npm run dev` (o Next.js sobe por padrão em `http://localhost:3000`).
5. No mesmo diretório do projeto, execute `code .` para abrir a pasta inteira no VS Code.

Se o comando `code` não estiver disponível no terminal, abra o VS Code e utilize **File → Open Folder...** para selecionar o diretório clonado.
